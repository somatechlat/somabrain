## 0. Binding rules

1. **No product code** in this plan until every mock below is complete and ISO-controlled.
2. **Agent Zero is a feature checklist, not a design.** Soma must be denser, clearer, more honest, multi-tenant, Capsule-native.
3. **IA law (`SOMA-UI-IA-001`)**: no triplicated homes. Welcome = composer hero only. Memory = `/memory` once. Models = Settings only. Brain = one surface.
4. **Language law:** never “slot”. Used for · Chat / Help / Memory. No SaaS / Eye of God.
5. **Every field real** — bind to `ModelIn`, Capsule config, tools catalog, memory APIs, neuromod, WS chat. No invented metrics.
6. **ISO document control** on every controlled doc (per `SOMA-UI-TEMPLATE-001`): Document Control table + Revision History `Version | Date | Author | Description`. Mock annexes may use the lightweight template note but must be listed in the register.
7. **What the agent must show** (better than A0): live model/provider, Used-for, memory pulse + one Memory screen, tool provenance, HITL, Capsule identity, neuromod honesty, gated surfaces with reasons.
